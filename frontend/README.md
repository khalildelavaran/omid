# رابط کاربری سامانه امید

رابط فارسی و راست‌چین سامانه با React، TypeScript و Vite پیاده‌سازی شده است.

## اتصال به بک‌اند Django

- در محیط production، رابط کاربری درخواست‌ها را به مسیرهای هم‌مبدأ مانند `/api/v1/auth/me/` و `/api/v1/applications/` ارسال می‌کند؛ بنابراین مرورگر نیازی به اتصال مستقیم به دامنه جداگانه API ندارد.
- Cloudflare Worker درخواست‌های `/api/*` را به origin بک‌اند منتقل می‌کند. در تنظیمات Worker، متغیر محیطی `OMID_API_ORIGIN` باید روی origin مستقل و قابل‌دسترسی HTTPS بک‌اند Django تنظیم شود؛ فقط origin وارد شود، نه مسیر `/api`.
- احراز هویت با session مبتنی بر cookie و CSRF خود Django انجام می‌شود. فقط حساب‌های داخلی فعال دارای نقش مجاز می‌توانند وارد شوند. اطلاعات واقعی تا زمان ورود موفق دریافت نمی‌شوند و رابط از داده‌های ساختگی به‌عنوان جایگزین خطا استفاده نمی‌کند.
- برای اجرای محلی، فایل `.env.example` را به `.env.local` کپی کنید. مقدار `VITE_API_BASE_URL` به‌صورت پیش‌فرض خالی است و Vite مسیرهای `/api` را از طریق proxy به `http://127.0.0.1:8000` می‌فرستد؛ بنابراین کوکی نشست و CSRF در مرورگر هم‌مبدأ می‌مانند. برای production این متغیر را خالی نگه دارید تا درخواست‌ها از مسیر Worker عبور کنند.

## اجرای محلی

از ریشه مخزن، بک‌اند را طبق [راهنمای backend](../backend/README.md) اجرا کنید. سپس:

```bash
cd frontend
npm install
cp .env.example .env.local
npm run dev
```

## ساخت نسخه نهایی

```bash
npm run build
npm run preview
```

در این مرحله ورود و دریافت فهرست پرونده‌های تسهیلاتی به API متصل شده‌اند. بخش‌های مشتریان، وظایف، گزارش‌ها و تنظیمات هنوز نیازمند اتصال اختصاصی به API هستند؛ عملیات تغییردهنده داده‌ها تا زمان پیاده‌سازی فرم‌ها و تطبیق دقیق قرارداد API غیرفعال می‌مانند.
