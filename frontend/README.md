# رابط کاربری سامانه امید

رابط فارسی و راست‌چین سامانه با React، TypeScript و Vite پیاده‌سازی شده است.

## اجرای محلی

```bash
cd frontend
npm install
cp .env.example .env.local
npm run dev
```

برای اتصال به بک‌اند Django، مقدار `VITE_API_BASE_URL` را روی نشانی سرویس تنظیم کنید. رابط فعلی تلاش می‌کند فهرست پرونده‌ها را از `/api/v1/applications/` دریافت کند؛ در صورت تنظیم نبودن API یا خطای شبکه، داده‌های نمایشی نشان داده می‌شوند. مسیرها و نام فیلدهای API باید با serializerهای فعال محیط مقصد تطبیق داده شوند.

## ساخت نسخه نهایی

```bash
npm run build
npm run preview
```

این رابط یک نقطه شروع برای پیاده‌سازی طراحی Figma است. بخش‌های مشتریان، وظایف، گزارش‌ها و تنظیمات هنوز نیاز به اتصال اختصاصی به API دارند؛ دکمه‌های عملیات حساس عمداً بدون endpoint معتبر، تغییری در داده‌های واقعی ایجاد نمی‌کنند.
