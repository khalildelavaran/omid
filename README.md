# سامانه امید (Omid CRM)

سامانه داخلی مدیریت ارتباط با مشتریان و فرایندهای شرکت مالی با تمرکز بر وام، تسهیلات، اعتباردهی، پیگیری پرونده‌ها، اسناد و ارتباط با مشتری.

> وضعیت: اسناد طراحی اولیه هستند. تصمیم‌های فنی و فرایندی باید پیش از بهره‌برداری با ذی‌نفعان، الزامات حقوقی و سیاست‌های امنیتی سازمان تأیید شوند.

## جهت‌گیری فنی پیشنهادی

- Backend: Python، Django و Django REST Framework
- Database: PostgreSQL
- Frontend: Next.js و TypeScript
- معماری: Modular Monolith؛ جداسازی ماژول‌ها در یک کدبیس و استقرار ساده در فاز اول
- استقرار: محیط داخلی سازمان، ابتدا با Docker Compose در محیط کنترل‌شده
- آزمون: آزمون‌های واحد، API، دسترسی و گردش‌کار

## اصول مهم

1. هر پرونده مشتری و تسهیلات باید مالکیت، وضعیت و تاریخچه تغییرات روشن داشته باشد.
2. دسترسی بر اساس نقش و دامنه دسترسی به پرونده‌ها کنترل شود؛ صرف مخفی کردن دکمه در رابط کاربری کافی نیست.
3. عملیات حساس و تغییرات مهم ثبت رویداد ممیزی داشته باشند.
4. رمزها، کلیدها، OTPها و اطلاعات محرمانه در مخزن کد یا لاگ ثبت نشوند.
5. درگاه پیامک، امضا و پرداخت از طریق adapter قابل‌تعویض یکپارچه شوند.
6. این سامانه در ابتدا جایگزین دفتر کل حسابداری یا سامانه بانکی اصلی فرض نمی‌شود.

## شروع کار

پس از تأیید معماری، پیاده‌سازی به‌ترتیب از اسکلت پروژه، تنظیمات امن، مدل کاربران و نقش‌ها، پرونده مشتری، گردش‌کار و سپس پرونده تسهیلات آغاز می‌شود. جزئیات در [نقشه راه](docs/architecture/roadmap.md) آمده است.
