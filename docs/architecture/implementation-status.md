# وضعیت پیاده‌سازی

این فایل وضعیت واقعی کد را از طراحی آینده جدا می‌کند.

## انجام‌شده
- [x] ساختار اولیه Django و تنظیمات environment
- [x] تنظیمات اولیه DRF با SessionAuthentication و پیش‌فرض دسترسی احراز‌شده
- [x] endpoint سلامت و تست‌های پایه
- [x] تنظیمات PostgreSQL و Docker Compose توسعه
- [x] فایل نمونه environment، قواعد Git ignore و راهنمای اجرا
- [x] workflow اولیه GitHub Actions برای Django checks و tests
- [x] مدل پایه UserProfile با نقش‌های کسب‌وکاری پیشنهادی
- [x] مدل اولیه Customer با UUID، شماره مشتری یکتا، نوع، وضعیت و مسئول پرونده
- [x] API اولیه فهرست/ایجاد/ویرایش/حذف مشتری با محدودیت staff
- [x] serializer با اعتبارسنجی اولیه مشتری حقیقی/حقوقی
- [x] migrationهای اولیه برای accounts و customers
- [x] مدل پرونده تسهیلات با مشتری، نوع محصول، مبلغ، مدت، وضعیت و مسئول
- [x] API فهرست/ایجاد/ویرایش/حذف پرونده‌های تسهیلات با فیلتر وضعیت، مشتری و جست‌وجو
- [x] تست‌های پایه API پرونده تسهیلات

## محدودیت‌های امنیتی و دامنه فعلی
- کنترل دسترسی مشتری و پرونده فعلاً فقط staff بودن را بررسی می‌کند؛ scope مبتنی بر نقش، تیم و مالکیت پرونده هنوز پیاده‌سازی نشده است.
- نقش UserProfile هنوز به مجوزهای Django متصل نشده و به‌تنهایی مجوزدهی مؤثر ایجاد نمی‌کند.
- شماره مشتری و شماره پرونده باید فعلاً توسط اپراتور/کلاینت ارسال شوند؛ تولید شماره ترتیبی امن/اتوماتیک هنوز وجود ندارد.
- حذف رکورد از API در این مرحله وجود دارد؛ پیش از بهره‌برداری باید سیاست حذف/بایگانی و محدودیت حذف پرونده‌های مالی اعمال شود.
- فیلد notes برای یادداشت ساده است؛ ثبت تاریخچه تغییرات و ممیزی کامل هنوز وجود ندارد.
- APIها نیازمند کاربر staff واردشده هستند؛ اتصال ورود امن پنل و جریان احراز هویت هنوز تکمیل نشده است.
- داشبورد Cloudflare فعلاً با داده نمونه کار می‌کند و به API جنگو متصل نیست.

## کارهای باقی‌مانده
- [ ] object-level permissions و ماتریس دسترسی نهایی
- [ ] transitionهای مجاز گردش‌کار، تأییدکننده مستقل و ثبت تصمیم
- [ ] حذف/بایگانی امن و audit trail
- [ ] بارگذاری امن اسناد
- [ ] اتصال پنل به API و طراحی جریان ورود
- [ ] استقرار API Django روی میزبان Python-compatible و پیکربندی اتصال امن
- [ ] lint و بررسی dependencyها در CI
- [ ] اتصال واقعی پیامک، پرداخت و امضا
- [ ] اجرای migrationها و تست‌ها در محیط CI و رفع خطاهای احتمالی
- [ ] hardening و تست امنیتی پیش از استقرار

## اعتبارسنجی
کد به مخزن افزوده شده، اما اجرای workflow و تست‌ها از این گفت‌وگو تأیید نشده است. وضعیت CI را در زبانه Actions مخزن بررسی کنید. این نسخه برای توسعه است و برای production آماده نیست.
