# وضعیت پیاده‌سازی

این فایل وضعیت واقعی کد را از طراحی آینده جدا می‌کند.

## انجام‌شده در اسکلت اولیه
- [x] ساختار اولیه Django
- [x] تنظیمات environment و جلوگیری از اجرای production بدون SECRET_KEY
- [x] تنظیمات اولیه DRF با SessionAuthentication و پیش‌فرض دسترسی احراز‌شده
- [x] endpoint سلامت عمومی با خروجی حداقلی
- [x] تست‌های پایه endpoint سلامت
- [x] تنظیمات پایه PostgreSQL برای توسعه
- [x] فایل نمونه environment و قواعد Git ignore
- [x] راهنمای اجرای backend
- [x] workflow اولیه GitHub Actions برای Django checks و tests

## هنوز پیاده‌سازی نشده
- [ ] مدل سفارشی User و سیاست‌های نقش
- [ ] مدل مشتری و پرونده
- [ ] object-level permissions
- [ ] گردش‌کار تسهیلات و تأییدها
- [ ] بارگذاری امن اسناد و ممیزی کامل
- [ ] پنل Next.js
- [ ] lint و بررسی dependencyها در CI
- [ ] اتصال واقعی پیامک، پرداخت و امضا
- [ ] hardening و تست امنیتی پیش از استقرار

## محدودیت اعتبارسنجی
کد به مخزن افزوده شده، اما اجرای workflow و تست‌ها هنوز از این گفت‌وگو تأیید نشده است. وضعیت CI را در زبانه Actions مخزن بررسی کنید. این اسکلت برای توسعه است و هنوز برای production آماده نیست.
